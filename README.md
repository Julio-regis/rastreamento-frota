# Sistema de Rastreamento de Frota para Coleta Urbana

Este projeto tem como objetivo monitorar, em tempo real, a localização dos caminhões responsáveis pela coleta de resíduos urbanos, proporcionando maior controle e eficiência nas operações.

O sistema utiliza o **Traccar Client** como aplicativo rastreador, instalado nos dispositivos dos veículos, para enviar a localização GPS ao servidor. Com essas informações, é possível acompanhar o deslocamento dos caminhões durante as rotas de coleta, identificar sua posição atual e verificar as ruas já atendidas.

## Funcionalidades

- 📍 Monitoramento em tempo real da localização dos caminhões.
- 🚛 Acompanhamento da frota durante as rotas de coleta.
- 🗺️ Visualização dos veículos no mapa.
- 📊 Auxílio na gestão e fiscalização da coleta urbana.
- ⏱️ Maior controle sobre o percurso e a operação dos veículos.

## Tecnologias Utilizadas

- Java
- Spring Boot
- Traccar Client
- API Traccar
- HTML, CSS e JavaScript
- Banco de Dados (conforme utilizado no projeto)

## Objetivo

O principal objetivo deste sistema é oferecer uma ferramenta que permita aos gestores acompanhar a execução da coleta urbana, visualizando em tempo real onde cada caminhão está localizado, contribuindo para uma gestão mais eficiente, transparente e organizada dos serviços de coleta de resíduos.
